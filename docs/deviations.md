# Changes from the pre-specified plan

The analysis plan was fixed before the runs in an internal document committed on October 28, 2026; it was not publicly registered, and the decision log of the study is internal. This file lists the changes from the pre-specified plan that affect the released code and results; the supplementary material describes the same changes (section "Changes from the pre-specified plan").

1. **Engine.** The plan specified transformers. Generation of the evaluated models now uses vLLM 0.32.0: Instant mode with greedy decoding in vLLM's batch-invariant mode, thinking mode with temperature 0.6, top-p 0.95, top-k 20, a fixed seed per request and at most 32,768 thinking tokens, with earlier turns' thinking dropped from multi-turn histories. Exception: Meerkat-70B (4-bit NF4 weights, not supported by vLLM) runs in Instant mode with transformers; vLLM has no batch-invariant mode for DeepSeek-V4-Flash. The patient/chart simulator is unchanged (transformers, greedy).
2. **Generation length limits.** The pre-specified limits of 200 tokens for targeted-ask question generation (`MAX_NEW_GEN` in `src/medgapqa/pipeline_k.py`) and 256 tokens for agent turns (`configs/agent.json`) are not applied: the runner sets no length limit, and generation stops at the end of the first JSON object, at the end-of-sequence token or at the end of the context. Meerkat-70B outputs of the transformers runs that had reached a limit were continued without one.
3. **Format re-request.** When a question set is re-requested because its format was invalid, only the first 1,024 tokens of the failed output are repeated in the prompt; the wording and structure of the re-request are unchanged.
4. **Thinking mode.** The 7 hybrid Qwen3 and Meerkat2 models and DeepSeek-V4-Flash also run in thinking mode (DeepSeek-V4-Flash is reported separately as a large model). The comparison of Instant with Think was specified in the plan without a decision rule; the improvement criterion fixed before the runs applies to the Instant main mean only. The plan listed thinking mode as a second priority; the thinking-mode runs were added on November 12, 2026 at the advisor's request, after the Instant runs, and the Instant–Think comparison has no decision rule.
5. **Difference from the earlier transformers runs.** On the Instant main mean, the cost of removal and the gains (Δ) differ from the earlier transformers runs by at most 0.004 over 7 measures, and every item-paired 95% interval includes zero; the same holds for DeepSeek-V4-Flash (supplement, engine check).

The pre-specified files (`src/medgapqa/pipeline_k.py`, `configs/agent.json` and the other files listed in `scripts/p2/run_pilot.py` and the frozen manifests in `prompts/`) are unchanged; the changes above are applied at run time by `scripts/think/veval.py` (and, for the continuation of the transformers runs, `scripts/think/hf_cont.py`).
